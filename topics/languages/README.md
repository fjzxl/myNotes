## 目录结构

- `japanese/` —— 日语
  - `syllabus.md` —— 日语学习大纲（兴趣向 · 标日 + JLPT 分级）：五阶段里程碑、每日 20 分钟模板、动漫/游戏素材使用法
  - `kana.md` —— 五十音笔记：假名总表、全表共通规律（分组记忆 / 辅音部位 / 一拍度量衡 / 7 个不按字母直拼的读音）、发音要点、易混辨析、长音与声调规则（以标日入门单元 p.2–16 为纲）
  - `kana-<罗马字>-row.md` —— 逐行笔记全 10 行（`kana-a-row` ~ `kana-wa-row`，拨音 `ん` 并入わ行篇）：每行含速览（笔画 / 字源）、发音要点、笔顺、易混辨析、例词与自测，按每日计划日推进
  - `kana-cards.md` —— 五十音闪卡：`Q :: A` 行内牌组，读卡 / 写卡两向共 235 张，建卡进度对齐每日计划
  - `kana-plan.md` —— 五十音每日计划（2026-10-12 起 · 三周）：每日学习 + 复习日历、验收标准

## 约定

- 每门语言一个子目录（如 `japanese/`），目录名用英文
- 学习总纲配合 [skill-learning](../../templates/skill-learning.md)，每次练习/自测用 [practice-log](../../templates/practice-log.md) 记录并复测
- 语法、词汇、台词语料等展开笔记放本语言子目录，从 [MOC - languages](../../notes/MOC%20-%20languages.md) 收录
