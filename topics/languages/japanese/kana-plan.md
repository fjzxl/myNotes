# 五十音每日计划（2026-10-12 起 · 三周）

> **定位**：零基础到假名全通过的逐日排程——每天约 20 分钟（新学 10 + 闪卡复习 5 + 听读 5），周日加餐可选。
> 内容依据 [[topics/languages/japanese/kana|五十音笔记]]（标日入门单元，教材 p.2–17）；总纲与中断规则见 [[topics/languages/japanese/syllabus|日语学习大纲]]。
> **开始日：2026-10-12（周一）**；目标：2026-10-31（周六）完成验收，即达成大纲「五十音 · 目标 2026-10 内」。

---

## 1. 每天 20 分钟怎么用

| 时段 | 时长 | 做什么 |
|------|------|--------|
| 新学 | 10 分钟 | 当日新行的假名：对照五十音笔记（见页首链接）总表认读 → 按笔顺（教材表 A/B，p.8–9）手写 3 遍 → 跟音频把该行读熟 |
| 闪卡复习 | 5 分钟 | 到期卡自测（闪卡牌组 / Anki / 纸质卡）——只复习，不学新卡 |
| 听读 | 5 分钟 | 当日行的音频跟读 3 遍 + 从已学行里随机点 5 个假名自测 |

- **周日加餐（可选，30–60 分钟）**：周复习（第 1、2 周日）/ 验收与缓冲（第 3 周末）。
- **当天太忙**：闪卡 5 分钟保底也算打卡（大纲：兴趣线 5 分钟音频也算）。
- **中断 ≤ 2 天**：只复习不赶新进度；**中断 ≥ 1 周**：退回上一个「周复习」行重新过关再前进。

## 2. 工具（第 1 天一次性建好）

- **闪卡**：牌组文件 [[topics/languages/japanese/kana-cards|五十音闪卡]]——每张假名两张卡（读卡「平+片 → 读音」、写卡「读音 → 平+片」），`正面 :: 背面` 行内格式，建卡进度表已按本日历排好。想用 Anki 就按同样两向建成牌组「JP·五十音」，每天新增 = 当日新学假名。不用软件就用纸质卡：正面假名、背面罗马字，按第 4 节复习节奏手动过。
- **音频**：标日 APP / 教材配套音频入门单元部分；没有的话用 MOJi辞书逐个假名单词发音替代。
- **默写本**：田字格或四线格练习本，笔顺照教材表 A（p.8 / PDF 25）、表 B（p.9 / PDF 26）。

## 4. 验收标准（10-31）

对应大纲「见假名能读、查词典无障碍」，四项全过即通过：

1. **乱序认读**：清音 46 + 浊音/半浊音 25 + 拗音 33 全表乱序（平、片假名各一遍），正确率 ≥ 95%（合计错 ≤ 5 个）；
2. **听写**：30 个音节（含至少 5 个易混对：ソ/ン、ツ/シ、ず/む 类），正确 ≥ 27；
3. **默写**：按行按段默写 46 清音平假名 + 片假名（笔顺不作硬性要求，字形正确即可）；
4. **试读**：50 词表（10-28 建）通读，卡壳 ≤ 3 词；并用假名输入在词典查到任意 5 个词。

未达标：只加练弱项（错得最多的行 / 易混组），2–3 天后用**新乱序**复测一次，不整表重学。
