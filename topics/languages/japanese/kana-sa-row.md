# さ行 · 五个音（さ し す せ そ）

> **逐行笔记第 3 篇**（对应 [每日计划](kana-plan.md) **10-14 周三**）。
> さ行只有一处「不按字母读」：**し读 shi**（全表 7 个不直拼音之一，最多的是た行）。后面对照组里 `si` 不是日语音，`す` 的罗马字与读音一致（su），别读成「苏」。
> 总表与通用规则见 [五十音笔记](kana.md)。
> 📖 **页码说明**：假名与罗马字见教材 p.2 五十音图；さ行发音（sa/se/so 辅音、し 与汉语 xi 相当、す 与 si 相近但嘴唇放松）见教材 p.4 清音讲解；笔顺对照表 A/B（p.8–9，PDF 25–26）；字源对照表 C/D（p.10，PDF 27）。

## 1. 本行速览

| 段 | 平假名 | 片假名 | 罗马字 | 笔画（平 / 片） | 字源（平 / 片） |
|------|--------|--------|--------|-----------------|-----------------|
| あ段 | さ | サ | sa | 3 / 3 | 左 / 散 |
| い段 | し | シ | **shi** | 1 / 3 | 之 / 之 |
| う段 | す | ス | **su** | 2 / 2 | 須 / 須 |
| え段 | せ | セ | se | 3 / 2 | 世 / 世 |
| お段 | そ | ソ | so | 1 / 2 | 曽 / 曽 |

- **笔画数为通行写法**：连笔书写时笔画会不同，写法以教材表 A（平）/表 B（片）的示范为准。
- 粗体罗马字是**读音不按字母直拼**的特殊音，本行只有 `shi`（`su` 与字母一致，不算），见第 2 节。
- `し` 只有 1 画，是全表单画假名之一。

## 2. 发音要点（教材 p.4）

`s` 在日语里是**齿龈擦音**：舌尖抵住上齿龈，气流从两侧摩擦而出，**不送气**。

| 假名 | 要点 | 对比汉语的提醒 |
|------|------|----------------|
| さ sa | 清音 | 汉语「撒 sā」气流偏强，日语更轻 |
| し shi | 舌尖位置比 `sa` **靠前**，靠近牙齿 | 别读成汉语「西 xī」的送气量，也别卷舌 |
| す su | 气流从舌齿缝持续摩擦出，**不要爆破** | 与汉语 si 相近但嘴唇更松；别读成「苏 sū」的送气量 |
| せ se | 清音 | — |
| そ so | 清音 | — |

**关键对照**：`さ` 和 `す` 罗马字只差一个元音，但舌位不同——`さ` 偏后、`す` 偏前，**不能互相替代**。这是本行最容易混的一对。

**浊音预告**：`さ行` 加浊点变 `ざ行`（za **ji** zu ze zo——其中 じ 读 ji 不读 zi）；`ぢ`/`づ` 分别与 `じ`/`ず` 同音（**两组**同音异形），10-22 学。

## 3. 笔顺（表 A p.8 / 表 B p.9，PDF 25–26）

- 平假名：さ 3 画、し 1 画、す 2 画、せ 3 画、そ 1 画。
- 片假名：サ 3 画、シ 3 画、ス 2 画、セ 2 画、ソ 2 画。
- `し` 与 `シ` 差别最大：平假名 `し` 是一笔弯钩（像拉长的 `し` 本身）；片假名 `シ` 是三笔（两点 + 一长撇）。
- `す`（2 画）：第一笔竖笔下行、底部绕**小环**后横向收笔，环要封口；第二笔是从左上向右下的短斜线，穿在中间。`ス`（2 画）是「撇 + 长捺」呈人字形。
- `そ`（1 画）**一笔连写**：横—折—弧一气呵成；`ソ`（2 画）是一短撇加一点，别和 `ン` 混（见第 4 节）。

## 4. 易混辨析

| 组 | 区分 |
|------|------|
| し / す | `し` 一笔到底、舌位靠前；`す` 有环、舌位偏中。写卡时先看有无那个圈。 |
| さ / そ | `さ` 3 画、上有一短横、收笔向下；`そ` **1 画一笔连写**、形似「Z」加弧钩。 |
| ソ / ン | 片假名第一对形近字：`ソ` 第二笔从上往下（读 so）；`ン` 第二笔从下往上（读 n）。看第二笔走向 + 起笔高低。 |
| シ / ツ | `シ` 读 shi、`ツ` 读 tsu。`シ` 前两笔横向在上；`ツ` 三笔纵向对齐。 |

## 5. 例词试读（限本行假名）

| 例词 | 罗马字 | 意思 |
|------|--------|------|
| さす | sasu | 指出、显现（差す） |
| しせい | shisei | 姿势（姿勢） |
| さ | sa | 差（差别） |
| しし | shishi | 狮子 |
| し | shi | 死；诗；四 |
| す | su | 醋 |
| すし | sushi | 寿司 |
| せかい | sekai | 世界 |
| そこ | soko | 那里；其处 |
| そら | sora | 天空 |

- 朗读重点：`すし` 的 `su` 是擦音不是爆破音，短、轻、平，别读成汉语「苏 sū」。
- 发音没把握的词，用 MOJi辞书 / [jisho.org](https://jisho.org) 逐个听真人发音。
