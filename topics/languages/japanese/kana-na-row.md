# な行 · 五个音（な に ぬ ね の）

> **逐行笔记第 5 篇**（对应 [每日计划](kana-plan.md) **10-16 周五**）。
> な行是 5 个**鼻音开头**的音节。`ぬ` 单独用的场合少，多出现在动词里（如 縫う ぬう＝缝）。
> 总表与通用规则见 [五十音笔记](kana.md)。
> 📖 **页码说明**：假名与罗马字见教材 p.2 五十音图；「な行和ま行辅音与汉语 n/m 基本相同」见教材 p.4 清音讲解；笔顺对照表 A/B（p.8–9，PDF 25–26）；字源对照表 C/D（p.10，PDF 27）。

## 1. 本行速览

| 段 | 平假名 | 片假名 | 罗马字 | 笔画（平 / 片） | 字源（平 / 片） |
|------|--------|--------|--------|-----------------|-----------------|
| あ段 | な | ナ | na | 4 / 2 | 奈 / 奈 |
| い段 | に | ニ | ni | 3 / 2 | 仁 / 二 |
| う段 | ぬ | ヌ | nu | 2 / 2 | 奴 / 奴 |
| え段 | ね | ネ | ne | 2 / 4 | 祢 / 祢 |
| お段 | の | ノ | no | 1 / 1 | 乃 / 乃 |

- **笔画数为通行写法**：连笔书写时笔画会不同，写法以教材表 A（平）/表 B（片）的示范为准。
- `の` 是**最常用的假名之一**（领格助词「的」，几乎每句话都有），单独 1 画一笔写成。
- な行**没有浊音**（不存在 `な行 + ゛`），这是它与其他辅音行最大的不同。

## 2. 发音要点（教材 p.4）

`n` 在日语里一律是**鼻音**：气流走鼻腔，口腔不阻塞。关键是**位置不变**——从 `な` 到 `の` 五个音里，`n` 的舌位基本不动，只换后面的元音。

| 假名 | 要点 | 对比汉语的提醒 |
|------|------|----------------|
| な na | 鼻音起点，`a` 开口 | 汉语「那 nà」带轻微爆破，日语 `な` 是持续鼻音 |
| に ni | 舌位靠前，`i` 窄 | — |
| ぬ nu | 唇略圆 | 少见单用，多在动词中（縫う nuu = 缝） |
| ね ne | 舌位靠前，`e` 开口比 `い` 大 | — |
| の no | 唇圆，`o` 稍靠后；`の` 始终是**清音** | 别拖成汉语「诺 nuò」那种开头的 n |

**关键对照**：`な` 和 `ぬ` 罗马字只差元音，口型不同（`な` 张口、`ぬ` 圆唇）。写卡时先看元音再拼。

**拨音 ん vs 行末 `な`**：行末的 `な` 是完整一拍（`はな` 花），`ん` 是**占位的拨音**（`はん` 半）。两者写法不同（`な` / `ん`），别混——拨音另见 [わ行・拨音 ん](kana-wa-row.md)。

## 3. 笔顺（表 A p.8 / 表 B p.9，PDF 25–26）

- 平假名：な 4 画、に 3 画、ぬ 2 画、ね 2 画、の 1 画。
- 片假名：ナ 2 画、ニ 2 画、ヌ 2 画、ネ 4 画、ノ 1 画。
- `な`（4 画）第一笔是右上短撇，第二笔长横，下面补两笔；初学者常漏第一笔。
- `に`（3 画）：左侧两小笔 + 右侧一笔 て 形；片假名 `ニ` 只要两横——笔画数都不同（3 vs 2）。
- `ぬ`（2 画）第二笔是**大环**，从右上绕一圈封口，别写成 `る` 那种带尾巴的小圈。
- `ね`（2 画）平假名第二笔带环且有伸出的小尾巴；片假名 `ネ` 是四笔（竖 + 三笔），写法完全不同。
- `の`（1 画）是一笔从左上到右下的圆，起笔收笔都在中间偏上。

## 4. 易混辨析

| 组 | 区分 |
|------|------|
| ね / れ | `ね` 收尾有小尾巴（带环）；`れ` 是长竖加一横、无环。 |
| ぬ / る | `ぬ` 是大环封口；`る` 是小圈 + 尾巴伸出。 |
| の / ね | 只差一笔。`の` 一笔圆；`ね` 两笔、有小竖。 |
| な / に | `な` 有上面的短撇和下面的折；`に` 只有两横加右半边。 |

## 5. 例词试读（本行假名为主，少量含已学的た行）

| 例词 | 罗马字 | 意思 |
|------|--------|------|
| な | na | 名（名前 なまえ）；「何（なに）」的首音节 |
| ない | nai | 不、没有（無い） |
| なか | naka | 里面、中间 |
| なつ | natsu | 夏天 |
| に | ni | 二（个数） |
| にち | nichi | 日子；日 |
| ぬ | nu | 缝（ぬう） |
| ぬの | nuno | 布 |
| ね | ne | 根（根 ね）；语气词「ね」（吧/呢） |
| ねこ | neko | 猫 |
| の | no | 的（领格助词，连接两个名词） |
| のう | nou | 农（農；农业 のうぎょう） |

- 朗读重点：`ない` 是「无」，`n` 鼻音要连着后面的 `ai`，不要断开成「那——衣」。
- 发音没把握的词，用 MOJi辞书 / [jisho.org](https://jisho.org) 逐个听真人发音。
