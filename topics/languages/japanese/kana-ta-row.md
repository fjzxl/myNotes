# た行 · 五个音（た ち つ て と）

> **逐行笔记第 4 篇**（对应 [[topics/languages/japanese/kana-plan|每日计划]] **10-15 周四**）。
> た行同样有两个不按字母读的音：**ち读 chi、つ读 tsu**。`つ` 还是**促音 っ 的同形不同长**那一对的关键。
> 总表与通用规则见 [[topics/languages/japanese/kana|五十音笔记]]。

## 1. 本行速览

| 段 | 平假名 | 片假名 | 罗马字 | 笔画（平 / 片） | 字源（平 / 片） |
|------|--------|--------|--------|-----------------|-----------------|
| あ段 | た | タ | ta | 4 / 3 | 太 / 多 |
| い段 | ち | チ | **chi** | 2 / 3 | 知 / 千 |
| う段 | つ | ツ | **tsu** | 1 / 3 | 川 / 川 |
| え段 | て | テ | te | 1 / 3 | 天 / 天 |

- **笔画数为通行写法**：连笔书写时笔画会不同，写法以教材表 A（平）/表 B（片）的示范为准。
- 粗体罗马字是**读音不按字母直拼**的特殊音，`chi` / `tsu` 见第 2 节。

## 2. 发音要点（教材 p.4；促音 p.6）

`t` 是**齿龈塞音**：舌尖抵上齿龈然后放开。与 `s`（さ行）舌位相同，区别是 `t` 有「堵住再放开」的爆破，`s` 是持续摩擦。

| 假名 | 要点 | 对比汉语的提醒 |
|------|------|----------------|
| た ta | 舌尖先堵后放 | 比汉语「他 tā」更轻，几乎不送气 |
| ち chi | 舌位比 `ta` **靠前**，接近牙齿 | 别读成汉语「吃 chī」的送气量 |
| つ tsu | 气流从舌齿缝挤出，**不爆破、不卷舌** | 与汉语「ci（雌）」相近但更短、唇更松，别拖长 |
| て te | 清音 | — |
| と to | 清音 | — |

**关键对照**：`つ`（tsu，清音）和 `っ`（促音）**写法相同、读法完全不同**：
- `つ` 读满一拍，发 `tsu`；
- `っ` 只占一拍但**几乎无声**，是停顿。
例：`つき`（月）两个音都响；`まっちゃ`（抹茶）里的 `っ` 是无声停顿。看到小写、写在词中，优先当促音处理。

**浊音预告**：`た行` 的浊音 `だ` 是后续 `ぢ`/`づ` 的来源，`ぢ`/`づ` 与 `じ`/`ず` 同音，10-22～23 学。

## 3. 笔顺（表 A p.8 / 表 B p.9，PDF 25–26）

- 平假名：た 4 画、ち 2 画、つ 1 画、て 1 画、と 2 画。
- 片假名：タ 3 画、チ 3 画、ツ 3 画、テ 3 画、ト 2 画。
- `た`（4 画）：第一笔短横、第二笔长横，右侧再补两笔成 `こ` 形。
- `ち`（2 画）：先一短横，再一笔长弧（下行后向右再回勾成环）；`チ`（3 画）第三笔与第二笔**交叉**——这是与 `テ` 的关键区别。
- `つ`（1 画）：一笔从右上向左下弯成弧；`ツ`（3 画）：两点 + 一长撇，**三笔纵向对齐**。
- `て`（1 画）：一笔横折后向左下弯成钩；`ト`（2 画）是「撇 + 短点（竖）」两笔，和平假名笔顺不同。

## 4. 易混辨析

| 组 | 区分 |
|------|------|
| つ / っ | 同形不同读。`つ` 发满 `tsu`；`っ` 无声停顿、只占一拍时长。词中看到小的，几乎一定是促音。 |
| ツ / シ | `ツ` 读 tsu、三笔纵向对齐；`シ` 读 shi、前两笔横向在上。 |
| チ / テ | `チ` 第三笔与第二笔**交叉**；`テ` 第一笔平写、第三笔**不交叉**。 |
| と / そ | `と` 2 画、下半带「こ」形小环；`そ` 1 画一笔连写、无环。 |

## 5. 例词试读（限本行假名）

| 例词 | 罗马字 | 意思 |
|------|--------|------|
| た | ta | 田 |
| たい | tai | 身体（体 たい） |
| たち | tachi | 复数后缀「〜達」（们，如 子供たち 小孩们） |
| ち | chi | 血 |
| ちか | chika | 地下（地下街 ちかがい） |
| つち | tsuchi | 土、土地 |
| つぎ | tsugi | 下次；接着 |
| つた | tsuta | 蔦（藤蔓、爬山虎） |
| て | te | 手 |
| と | to | 户（戸）；助词 と（引用/假定） |

- 朗读重点：`つぎ` 里 `tsu` 要扁、要短，不要念成「次 cì」那种卷舌。
- 发音没把握的词，用 MOJi辞书 / [jisho.org](https://jisho.org) 逐个听真人发音。
