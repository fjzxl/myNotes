# 五十音闪卡

> **卡片格式**：一行一卡，`正面 :: 背面`。自测三步：看到正面 → 口头 / 笔头作答 → 核对背面。答错的卡在行首加 🔁 标记、下次优先过，连对两天后取消标记；某张卡 🔁 累计 3 次，把该假名登记到 [[topics/languages/japanese/kana-plan|每日计划]] §5「反复出错的假名」。
> **每个假名两张卡**：**读卡**（平+片 → 读音，出声读）与**写卡**（读音 → 平+片，在田字格默写、顺带回忆笔顺）。片假名专项：过读卡时遮住平假名，只认片假名（对应计划 10-21）。
> **建卡节奏**：对照下方「建卡进度」表，每天只学当天新行，不一次全表上阵；复习只过已学部分。Foam 没有间隔复习插件，用 🔁 标记法 + 计划日历手动滚动即可；想导 Anki 时按 `::` 分列导入（正面/背面各一列）。
> 知识依据：[[topics/languages/japanese/kana|五十音笔记]]；排程与验收：[[topics/languages/japanese/kana-plan|每日计划]]。

## 一、清音 46（10 行 + ん）

### あ行 a（10-12）

**读卡**

- あ ア :: a
- い イ :: i
- う ウ :: u
- え エ :: e
- お オ :: o

**写卡**

- a :: あ ア
- i :: い イ
- u :: う ウ
- e :: え エ
- o :: お オ

**随行特殊卡（10-12）**

- 助词 は 的读音 :: wa（不在句中作助词时仍读 ha）
- 助词 へ 的读音 :: e（作助词时不读 he）
- を 的读音 :: o（现代日语几乎只作宾格助词，不写 wo）

## 四、易混辨析卡（教材 p.7）

> 识形卡：正面问怎么区分，背面是区分口诀（依据教材表 A/B）。排期对齐计划：10-18 周①建 3 张（限已学行的 ず/む、め/ぬ、な）；ら/ろ/ち、れ/わ 要等 10-20 学完ら・わ行再建；10-25 周②建片假名 4 张。

**平假名 · 周①（10-18）**

- ず / む 怎么区分 :: 最后一笔向下伸直是 zu；向右拐并翘上去是 mu
- め / ぬ 怎么区分 :: 最后一笔按曲线自然收尾是 me；再画个小圈（闭合）是 nu
- な 的字形要点 :: 源自「奈」草书；第三、四笔写在偏右位置

**平假名 · 随ら・わ行（10-20）**

- ら / ろ / ち 怎么区分 :: 两笔断开、第二笔近直带弯是 ra；一笔连写先横后折是 ro；收尾小圈是 chi
- れ / わ 怎么区分 :: 最后一笔向下再向右伸出的是 re；画圆圈的是 wa

**片假名（10-25）**

- ソ / ン 怎么区分 :: 第二笔从上往下写是 ソ（so）；从下往上写是 ン（n）——看第二笔走向与起笔高低
- ツ / シ 怎么区分 :: 第三笔从上往下写是 ツ（tsu）；从下往上写是 シ（shi）——ツ 三笔纵向对齐、シ 前两笔横向在上
- チ / テ 怎么区分 :: チ 第一笔右上→左下、第三笔与第二笔交叉；テ 第一笔平写、第三笔不交叉
- ク / ワ 怎么区分 :: ク 瘦而斜；ワ 第一笔是短竖、横笔约两倍宽

## 五、规则卡

### 长音 / 拨音 / 促音 / 清化（10-26，依据笔记 §4.4、§5）

- 日语长音占几拍 :: 两拍；长短音辨义（え 画画 / ええ 肯定；くろ 黑色 / くろう 吃苦）
- 长音：あ段怎么写 :: + あ（おかあさん 母亲）
- 长音：い段怎么写 :: + い（ほしい 想要）
- 长音：う段怎么写 :: + う（たいふう 台风）
- 长音：え段怎么写 :: + い（读 e：えいが 电影）；例外用 え：おねえさん、ええ
- 长音：お段怎么写 :: + う 为主（こうつう 交通）；少数 + お：おおきい、とおい
- 片假名长音怎么写 :: 一律用长音符「ー」（キー 钥匙、コーヒー 咖啡）
- 拨音 ん :: 独占一拍，长度强度与前后音相同（さんぽ 散步）
- 促音 っ :: 一拍无声停顿，只出现在 か・さ・た・ぱ 行前（さっか 作家）
- 元音清化 :: i / u 夹在清辅音之间或位于句尾时几乎不出声（です des(u)、した k(i)ta）

### 声调与外来词（10-27，依据笔记 §7、§8）

- 声调铁律一 :: 第 1、2 个音节高低必不同
- 声调铁律二 :: 一个词或没有下降、或只有一处下降（听到下降 = 一个词说完）
- 外来词专用音节 :: ツァ、ファ、ウィ、ティ、フィ、シェ、ジェ 等——见到能读即可，不必主动拼写
