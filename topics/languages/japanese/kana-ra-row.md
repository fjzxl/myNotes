# ら行 · 五个音（ら り る れ ろ）

> **逐行笔记第 9 篇**（对应 [每日计划](kana-plan.md) **10-20 周二**，与わ行・ん同日）。
> ら行的 `r` 是**闪音（弹音）**，和 `l` 不同——中文母语者最容易把日语 `ra/ri/ru/re/ro` 读成汉语的 `la/li/lu/le/lo`。
> 总表与通用规则见 [五十音笔记](kana.md)。
> 📖 **页码说明**：假名与罗马字见教材 p.2 五十音图；ら行辅音（与汉语 l 相近但舌位稍靠后、舌尖轻弹上腭后迅速离开）见教材 p.5，「だ・な・ら 的区别」与 ら 的发音要领见 p.16（Ⅳ 第 2 节）；笔顺对照表 A/B（p.8–9，PDF 25–26）；字源对照表 C/D（p.10，PDF 27）。

| う段 | る | ル | ru | 1 / 2 | 留 / 流 |

- ら行是**清音行中最难读的一行**，因为 `r` 在汉语里没有对应音。

## 2. 发音要点（教材 p.5；ら 的发音要领 p.16）

日语 `r` 是**闪音（弹音，tap/flap）**：舌尖抵住上齿龈**一瞬**，然后弹开，连到后面的元音。ら行五个音的发音部位完全相同，只是后面的元音不同。

| 假名 | 要点 | 对比汉语的提醒 |
|------|------|----------------|
| ら ra | 舌尖抵齿龈一瞬弹开 | **绝对不能读成汉语「拉 lā」的边音 l**（不是卷舌，卷舌指 zh/ch/sh/r）——这是中国人最大的错误 |
| り ri | 同ら，但舌位更前 | 别读成「里 lǐ」 |
| る ru | 舌尖弹开 + 圆唇 u | 别读成「路 lù」 |
| れ re | 舌尖弹开 + 开口 e | 别读成「热 lè」 |
| ろ ro | 舌尖弹开 + `o` | 别读成「落 luò」的 l |

**怎么练**：把 `ら行` 读快一点（`らりるれろ` 连成一串），舌尖就会自然「弹」。读慢反而像汉语的 `l`。这是**速度决定发音**的典型辅音。

**浊音预告**：`ら行` **没有浊音**（不存在 `ら行 + ゛`）。没有浊音的还有 `あ行`、`な行`、`ま行`、`や行`、`わ行`（`や行`、`わ行` 是半元音行；日语只有か・さ・た・は 四行派生浊音）。

## 3. 笔顺（表 A p.8 / 表 B p.9，PDF 25–26）

- 平假名：ら 2 画、り 2 画、る 1 画、れ 2 画、ろ 1 画。
- 片假名：ラ 2 画、リ 2 画、ル 2 画、レ 1 画、ロ 3 画。
- `ら`（2 画）：第一笔短横带一点弯，第二笔是**大弧**向左下再收；和 `ぬ` 的区别在起笔方向。
- `り`（2 画）是两个短竖（左右各一），右边的略弯。
- `る`（1 画）：**一笔连写**——先横、再向左下折，最后绕成**小圈**并甩尾（与 `ろ` 只差这个小圈）；`ル`（2 画）是「撇 + 捺」两笔成人字形。
- `れ`（2 画）：左上短撇 + 右下带弯的长竖；`レ`（1 画）只是一笔折——写法和平假名完全不同。
- `ろ`（1 画）：一笔先横再向左下弯成弧；`ロ`（3 画）是「竖 + 横折 + 横」三笔成方框，和平假名完全不一样。

## 4. 易混辨析

| 组 | 区分 |
|------|------|
| ら / ぬ | 都是 2 画带弧。`ら` 起笔是横带弯；`ぬ` 起笔是斜撇。 |
| り / い | `り` 有两个短竖；`い` 是两笔弧形、无竖。 |
| る / ろ | `る` 有圈；`ろ` 无圈只有弧。 |
| れ / ね | `れ` 是短撇 + 长竖；`ね` 是短竖 + 带环弧。 |
| レ / ロ | `レ` 一笔折；`ロ` 三笔方框。 |

## 5. 例词试读（本行假名为主，少量含已学行假名）

| 例词 | 罗马字 | 意思 |
|------|--------|------|
| らい | rai | 来（到来，未来 みらい） |
| らく | raku | 乐；轻松（楽 らく） |
| りす | risu | 松鼠（栗鼠） |
| り | ri | 理（理由 りゆう）；利（便利 べんり） |
| りき | riki | 力气（力 りき） |
| る | ru | 动词词尾（如 乗る のる＝乘坐） |
| るす | rusu | 不在家（留守） |
| るり | ruri | 琉璃（彩色玻璃） |
| れい | rei | 令、命令；例（例 れい） |
| ろ | ro | 炉（炉 ろ）；路（道路 どうろ 的 ろ） |
| ろく | roku | 六 |
| ろん | ron | 论（如 議論 ぎろん 的 ろん） |
| らん | ran | 乱 |

- 朗读重点：`らく`（乐）里 `ra` 舌尖要**弹一下**而不是滑成 `la`。可以先快速读 `らりるれろ` 三遍再进词。
- 发音没把握的词，用 MOJi辞书 / [jisho.org](https://jisho.org) 逐个听真人发音。
