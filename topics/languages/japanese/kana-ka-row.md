# か行 · 五个音（か き く け こ）

> **逐行笔记第 2 篇**（对应 [每日计划](kana-plan.md) **10-13 周二**）。
> か行是第一个**辅音行**。往后 さ/た/な/は/ま/ら 各行都是「换一个辅音 + 同样的 5 个元音」，所以か行学的是**结构**，不只是 5 个新词。
> 总表与通用规则见 [五十音笔记](kana.md)。
> 📖 **页码说明**：假名与罗马字见教材 p.2 五十音图；`k` 的发音与元音清化见教材 p.4 清音讲解（舌位/送气细节为通用语音学补充）；笔顺对照表 A/B（p.8–9，PDF 25–26）；字源对照表 C/D（p.10，PDF 27）。

## 1. 本行速览

| 段 | 平假名 | 片假名 | 罗马字 | 笔画（平 / 片） | 字源（平 / 片） |
|------|--------|--------|--------|-----------------|-----------------|
| あ段 | か | カ | ka | 3 / 2 | 加 / 加 |
| い段 | き | キ | ki | 4 / 3 | 幾 / 幾 |
| う段 | く | ク | ku | 1 / 2 | 久 / 久 |
| え段 | け | ケ | ke | 3 / 3 | 計 / 介 |
| お段 | こ | コ | ko | 2 / 2 | 己 / 己 |

- **笔画数为通行写法**：连笔书写时笔画会不同，写法以教材表 A（平）/表 B（片）的示范为准。
- **字源只用来帮记字形**，不必背；教材表 C/D 的具体字形以课本为准。
- `く` 是平假名里**笔画最少**的一个（1 画一笔到底）；片假名 `ク` 是 **2 画**。单画平假名还有 し、つ、て、そ、の、ひ、へ、る、ろ、ん 等。

## 2. 发音要点（教材 p.4）

`k` 是**舌根爆破音**（软腭音）：舌根抵住软腭，把气流堵住再突然放开。它不是摩擦音——摩擦（气流从窄缝挤出去）是 `さ行` 的 `s` 那种方式。

| 假名 | 要点 | 对比汉语的提醒 |
|------|------|----------------|
| か ka | 词首、词中都是清音 | 汉语「咖 kā」偏送气，日语 `k` 气流更轻，词中几乎不爆破 |
| き ki | 同上 | — |
| く ku | 唇不圆、舌位偏前 | 别发成汉语「苦 kǔ」的送气量 |
| け ke | 同か | — |
| こ ko | 送气最弱的一个 | 日语 `k` 系列整体不送气，靠**后续元音清化**补偿，听感才「脆」 |

**元音清化预告**：`き`/`く` 夹在两个 `k` 音节之间或落在句尾时，`i`/`u` 只留口形不出声（`きき` → `kiki`）。这是日语听起来「短促干净」的关键，教材入门单元后半段会正式讲，先混个脸熟。

**浊音/半浊音预告**：`か行` 五个假名**全部**可以加浊点变 `が行`（ga gi gu ge go，10-22 学）。半浊音 `ぱ行` 是 `は行` 派生的，与 `か行` 无关，别混。

## 3. 笔顺（表 A p.8 / 表 B p.9，PDF 25–26）

- 平假名：か 3 画、き 4 画、く 1 画、け 3 画、こ 2 画。
- 片假名：カ 2 画、キ 3 画、ク 2 画、ケ 3 画、コ 2 画。
- `き` 是 4 画：两横、一斜竖贯穿，末笔向左下弯成短弧（印刷体；手写常把后两笔连成一笔）。写的时候横要平、竖要正。
- `こ`（2 画）vs `コ`（2 画）：平假名 `こ` 是上下两横（下横带弧）；片假名 `コ` 带左侧竖折、三边成框。笔顺完全不同，别照着平假名写片假名。
- `ク`（2 画）：一斜撇、一短横（起笔接撇的上端，向右下微斜）；`ケ`（3 画）：一短斜撇、一横、一长斜（末笔从横的中部向左下撇出）。

## 4. 易混辨析

| 组 | 区分 |
|------|------|
| く / し | `く` 的 k 是舌根**爆破**（堵住再放开），舌位在后；`し` 的 s 是齿龈摩擦，舌尖抵上齿龈。读 `ka ki ku ke ko` 时舌根别往前挪。 |
| こ / そ | 只差一横。`こ` 是「二」；`そ` 上半多一横、下半带弧。 |
| キ / ー | `キー`（key，钥匙）里 `ー` 是**长音符**、占一拍、不是假名，别和 キ 的横画混。 |
| か / が | 后者右上角两点，今天不学，见到时知道「那是浊音」即可。 |

## 5. 例词试读（限本行假名）

| 例词 | 罗马字 | 意思 |
|------|--------|------|
| かさ | kasa | 伞 |
| かき | kaki | 柿子（柿）；蚝（牡蛎）；篱笆（垣）——同音异义 |
| き | ki | 木、树 |
| くき | kuki | 茎 |
| く | ku | （形容词连用形词尾：高・く・ない 的 く） |
| こ | ko | （量词「個」的读音：一個 いっこ） |
| こい | koi | 恋（恋情）；同音「鯉」＝鲤鱼 |
| ここ | koko | 这里、此处 |
| かきくけこ | kakikukeko | 五十音（假名本身构成的词） |

- 朗读重点：`く` 不要读成汉语「哭 kū」的哭腔；日语 `ku` 短、轻、平。
- 发音没把握的词，用 MOJi辞书 / [jisho.org](https://jisho.org) 逐个听真人发音。
