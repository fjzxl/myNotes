# わ行 · 两个新音（わ を）与拨音 ん

> **逐行笔记第 10 篇**（对应 [[topics/languages/japanese/kana-plan|每日计划]] **10-20 周二**，与ら行同日）。
> わ行是**收尾行**：清音表到 `わ` 就结束了，剩下的 `を` 只是个助词。拨音 `ん` 也在这一天收尾——它是**不属于任何行**的特殊音，写法、用法都和其他假名不同。
> 总表与通用规则见 [[topics/languages/japanese/kana|五十音笔记]]。
> 📖 **页码说明**：假名与罗马字（わ行 い/う/え 段借用、を）见教材 p.2 五十音图（含「お和を、じ和ぢ、ず和づ 字形不同但发音相同」）；わ行发音（半辅音、わ行的 い う え を 与あ行相同）见教材 p.5；拨音 `ん` 的发音与 m/n/ng 变化见 p.5–6；笔顺对照表 A/B（p.8–9，PDF 25–26）；字源对照表 C/D（p.10，PDF 27）。

## 1. 本行速览

| 段 | 平假名 | 片假名 | 罗马字 | 笔画（平 / 片） | 字源（平 / 片） |
|------|--------|--------|--------|-----------------|-----------------|
| あ段 | わ | ワ | wa | 2 / 2 | 和 / 和 |
| い段 | （借用 い） | （借用 イ） | — | — | — |
| う段 | （借用 う） | （借用 ウ） | — | — | — |
| え段 | （借用 え） | （借用 エ） | — | — | — |
| お段 | を | ヲ | **o** | 3 / 3 | 遠 / 乎 |
| 拨音（不属段） | ん | ン | n | 1 / 2 | 无 / 尔 |

- **笔画数为通行写法**：连笔书写时笔画会不同，写法以教材表 A（平）/表 B（片）的示范为准。
- わ行只有 **2 个新音**（わ/を），加上や行的 3 个（や/ゆ/よ）和拨音 `ん`，清音表合计 **46 音**。
- `を` 现代日语里**读 o，不读 wo**——它几乎只作宾格助词出现（例：「本 を 読む」读书 的 を）。
- 拨音 `ん` 单独列在下方：它**不是行**，写法是 `ん/ン`（不是 `ね/ネ`）。

## 2. 发音要点（教材 p.5；拨音 p.5–6）

| 假名 | 要点 | 对比汉语的提醒 |
|------|------|----------------|
| わ wa | `w` 是半元音，唇略圆后滑向 `a` | 比汉语「蛙 wā」短，唇不前突太多 |
| を o | 读 o；作为助词时几乎总是标音为 o | 别读成 wo；现代口语里 `を` 不读 w 起头 |
| ん n | 鼻音收尾，独立占一拍；实际音值随前后音微变（m/n/ŋ 三种） | 别和前面的假名拼成一个音——它自己就是一拍 |

**拨音 ん 的位置规则**（重要）：
- ✅ 出现在**词中**：`しんぶん`（报纸）、`みんな`（大家）——一个词里可以有两个 ん
- ✅ 出现在**词末**收尾：`さん`（三）、`にほん`（日本）、`らーめん`（拉面，长音后接 ん）
- ❌ **不能出现在词首**：`ん` 开头不合法

**读音提示**：ん 的实际读音随前后音变化（后接 ま行/ぱ行 时像 m、后接 さ行 等时像 n、后接 か行/が行 时像 ng）。先统一按 n 读，教材在拨音节（p.5–6）讲它的变化。

## 3. 笔顺（表 A p.8 / 表 B p.9，PDF 25–26）

- 平假名：わ 2 画、を 3 画、ん 1 画。
- 片假名：ワ 2 画、ヲ 3 画、ン 2 画。
- `わ`（2 画）：第一笔短竖带一点弯，第二笔是大弧；和 `れ` 的区别在弧的方向（`わ` 往右绕，`れ` 往左伸）。
- `を`（3 画）vs `お`：`お` 右上**带点**、起笔是横；`を` **无点**、起笔是竖向笔画（教材表 A）。
- `ん`（1 画）：一笔连写——先向右下弯、再挑向右上收笔，不是 `ね/ネ`（带环）。

## 4. 易混辨析

| 组 | 区分 |
|------|------|
| わ / れ | `わ` 是短竖 + 右绕弧；`れ` 是短撇 + 左伸竖。 |
| を / お | `お` 右上带点；`を` 无点、起笔是竖向笔画（`お` 起笔是横）。这是全表形近度最高的一对。 |
| を / ヲ | 平假名和片假名字形差异大，不要互相套用笔顺。 |
| ん / ね | `ん` 两笔成「人」；`ね` 带环。片假名 `ン` 与 `ネ` 也完全不同。 |
| ソ / ン | `ソ` 第二笔从上往下（so）；`ン` 第二笔从下往上（n）。 |

## 5. 例词试读

| 例词 | 罗马字 | 意思 |
|------|--------|------|
| わ | wa | 和（和平 わへい）；轮（輪 わ） |
| わけ | wake | 理由、翻译（訳） |
| わんこ | wanko | 小狗（昵称）；一碗的量（方言） |
| わたし | watashi | 我 |
| を | o | （宾格助词，接他动词） |
| ほん | hon | 书 |
| きん | kin | 金 |
| さん | san | 三 |
| にほん | nihon | 日本 |
| らーめん | raamen | 拉面（长音 + 拨音） |

- 朗读重点：`ほん`（书）的 `ん` 舌尖抵齿龈、鼻腔共鸣拖一拍；不要发成「奔 bēn」。
- 发音没把握的词，用 MOJi辞书 / [jisho.org](https://jisho.org) 逐个听真人发音。
