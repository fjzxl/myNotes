# あ行 · 五个元音（あ い う え お）

> **逐行笔记第 1 篇**（对应 [[topics/languages/japanese/kana-plan|每日计划]] **10-12 周一**）。
> あ行是全表地基：其余九行都是「辅音 + 这 5 个元音」，元音发准了，后面每一行才不会歪。
> 总表与通用规则见 [[topics/languages/japanese/kana|五十音笔记]]；发音依据教材 p.3 元音节。

## 1. 本行速览

| 段 | 平假名 | 片假名 | 罗马字 | 笔画（平 / 片） | 字源（平 / 片，表 C/D） |
|------|--------|--------|--------|-----------------|--------------------------|
| あ段 | あ | ア | a | 3 / 2 | 安 / 阿 |
| い段 | い | イ | i | 2 / 2 | 以 / 伊 |
| う段 | う | ウ | u | 2 / 3 | 宇 / 宇 |
| え段 | え | エ | e | 2 / 3 | 衣 / 江 |
| お段 | お | オ | o | 3 / 3 | 於 / 於 |

- 字源（教材 p.10）只用来**帮记字形**：想不起 あ 长什么样时，想想「安」的草书轮廓。记住表 A/B 的正确写法才是目标。
- あ行没有「印刷体与手写体差异」问题（教材 p.7 列的 き、さ、そ 等都不在本行），照表 A/B 写即可。

## 2. 发音要点（教材 p.3）

**两条通用铁律**（适用于全部 5 个元音，也适用于全表）：

1. 口形比汉语**小**；
2. 发音全程**口形和音高不变**——没有汉语那种滑动，也不在一个音节内变调。

| 假名 | 要点 | 对比汉语的提醒 |
|------|------|----------------|
| あ | 上下开口比汉语 a 小，舌头位置稍靠后 | 别照「啊」的口径张大嘴 |
| い | 上下开口与汉语基本相同，左右略窄 | 口形整体放松，不要咧紧 |
| う | **全行最大差异音**：嘴唇几乎放平、不向前突出；轻咬上下齿，稍张嘴发 u | 汉语 u 是圆唇前突，日语完全不是 |
| え | 与汉语 ei 的**前半部分**或 ie 的**后半部分**相似（教材原文）；本质是单元音 | 别拖成双元音，也别发成汉语「饿」 |
| お | 嘴上下张开、唇略圆，舌位比汉语 o 稍靠后，口形略紧张 | 别照「哦」的圆唇程度 |

**元音连读**（p.3–4）：`あい`（爱）、`うえ`（上面）、`あおい`（蓝）这类连续元音，两个元音**长短、轻重基本相同**——不像汉语「爱 ai」一主一辅、前重后轻。今天读例词时专门体会这一点。

## 3. 笔顺（表 A p.8 / 表 B p.9，PDF 25–26）

- 平假名：あ 3 画、い 2 画、う 2 画、え 2 画、お 3 画。
- 片假名：ア 2 画、イ 2 画、ウ 3 画、エ 3 画、オ 3 画。
- あ、お 都是「绕圈 + 收笔」的 3 画结构，圈要写圆、封口；笔顺照表 A 的 ①②③ 示范，先慢写 3 遍再提速。
- エ、オ 区分看第三笔：エ 第三笔是底部**平横**；オ 第三笔是**短撇**，从竖笔上侧向左下撇出（照表 B 示范）。

## 4. 易混辨析

| 组 | 区分 |
|------|------|
| あ / お | 全表第一对形近字：都由「圈 + 收笔」构成。あ 的第三笔是右侧**竖笔**、整体瘦长；お 的第三笔是右侧**短点**、字形略方正。写混的唯一解法：对照表 A 并排各写 5 遍。 |
| ア / マ（预习） | マ 是ま行第一个假名（10-19 学），先混个脸熟：ア 第二笔是从横画右端向左下的长撇；マ 第一笔是横折、第二笔补左侧斜笔，两笔合成三角。今天不用记。 |

## 5. 例词试读（只用本行假名）

| 例词 | 罗马字 | 意思 |
|------|--------|------|
| あい | ai | 爱 |
| いえ | ie | 房子 |
| うえ | ue | 上面 |
| え | e | 画 |
| おい | oi | 外甥 |
| あう | au | 相遇 |
| あお | ao | 蓝色 |
| あおい | aoi | 蓝的（教材 p.3 连读示例） |
| いい | ii | 好 |

- 朗读重点：`あい`、`あう`、`あおい` 不要滑成汉语双元音——a 和 i / u / o 各占一拍、轻重相同。
- 发音没把握的词，用 MOJi辞书 / [jisho.org](https://jisho.org) 逐个听真人发音。
