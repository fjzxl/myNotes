# や行 · 三个新音（や ゆ よ）

> **逐行笔记第 8 篇**（对应 [每日计划](kana-plan.md) **10-19 周一**，与ま行同日）。
> や行是**半辅音行**：い段和え段没有自己的假名，直接借用あ行的「い」「え」。加上拗音的 `ゃゅょ`，它靠大小写区分，是全表最需要留意「哪个是本行」的一行。
> 总表与通用规则见 [五十音笔记](kana.md)。
> 📖 **页码说明**：假名与罗马字（や行 い/え 段借用）见教材 p.2 五十音图；や行发音（半辅音、や行的 い え 与あ行发音相同）与拗音构成见教材 p.5；笔顺对照表 A/B（p.8–9，PDF 25–26）；字源对照表 C/D（p.10，PDF 27）。美容院/病院的拍数对比例为通用常识补充。

## 1. 本行速览

| 段 | 平假名 | 片假名 | 罗马字 | 笔画（平 / 片） | 字源（平 / 片） |
|------|--------|--------|--------|-----------------|-----------------|
| あ段 | や | ヤ | ya | 3 / 2 | 也 / 也 |
| い段 | （借用 い） | （借用 イ） | — | — | — |
| う段 | ゆ | ユ | yu | 2 / 2 | 由 / 由 |
| え段 | （借用 え） | （借用 エ） | — | — | — |
| お段 | よ | ヨ | yo | 2 / 3 | 与 / 与 |

- **笔画数为通行写法**：连笔书写时笔画会不同，写法以教材表 A（平）/表 B（片）的示范为准。
- や行只有 **3 个新音**（や/ゆ/よ）；加上わ行的 2 个新音（わ/を）和拨音 `ん`，清音总数才是 46。
- や行的罗马字都**以 y 开头**，但 `y` 是半元音、不单独成拍；单独的 `やゆよ` 读作 ya / yu / yo。

## 2. 发音要点（教材 p.5）

| 假名 | 要点 | 对比汉语的提醒 |
|------|------|----------------|
| や ya | `y` 半元音快速滑向 `a` | 别读成汉语「呀 yā」的 `y` 那样拖长 |
| ゆ yu | `y` 滑向圆唇 `u` | 唇要圆，别滑成 `iu` |
| よ yo | `y` 滑向 `o` | 短促，别拖成「哟 yō」 |

**拗音预告**（10-24）：把 `やゆよ` **写小一号**（`ゃゅょ` / `ャュョ`）放在い段假名后面，就变成**拗音**——一个音节占**一拍**，不是两拍。
- 平假名：き + ゃ = きゃ（kya）；片假名：キ + ャ = キャ（kya）。

**关键对照**：`や`（大）和 `ゃ`（小）**发音不同**：
- `びよういん`（美容院）= bi + yo + u + i + n，**5 拍**
- `びょういん`（病院）= byo + u + i + n，**4 拍**
这是日语「一拍 vs 两拍」最直观的区别（拗音只算一拍），歌词里也听得出来。

## 3. 笔顺（表 A p.8 / 表 B p.9，PDF 25–26）

- 平假名：や 3 画、ゆ 2 画、よ 2 画。
- 片假名：ヤ 2 画、ユ 2 画、ヨ 3 画。
- `や`（3 画）：第一笔是右上短撇，第二笔长横，第三笔是斜撇；`ヤ`（2 画）形如「一 + 人」（一横、下方一笔「人」形）。
- `ゆ`（2 画）：一笔弯成大 U 形从左到右再收；`ユ`（2 画）是一横 + 一笔竖折（左竖连底横）。
- `よ`（2 画）：第一笔是上部**短横**；第二笔从右上方起笔、向下穿过中心、在左下方绕成**圆环**收尾；`ヨ`（3 画）是**横折 + 两横**——左侧有竖、竖不在中间，这是 `よ` 与 `ヨ` 的关键区别。
- 拗音的 `ゃゅょ` 写法与 `やゆよ` 完全相同，只是**占半格、写小**。

## 4. 易混辨析

| 组 | 区分 |
|------|------|
| や / よ | 平假名：`や` 第二笔（横）之后是斜撇；`よ` 是短横 + 一笔绕环（2 画）。片假名：`ヤ` 下方是「人」形；`ヨ` 左侧有竖（横折起笔）。 |
| ゆ / ヨ | `ゆ` 有竖/弯；`ヨ` 是横折 + 两横（左侧有竖）。 |
| や / ゃ | 只差大小写。大的 `や` 自成一拍，小的 `ゃ` 与前一个假名合成拗音、共占一拍，且只出现在别的假名后。 |
| ヨ / ユ | `ヨ`（3 画）横折 + 两横；`ユ`（2 画）一横 + 竖折——数笔画即可区分。 |

## 5. 例词试读（限本行假名）

| 例词 | 罗马字 | 意思 |
|------|--------|------|
| や | ya | 矢（箭）；……屋（店铺后缀，如 パン屋 面包店） |
| やま | yama | 山 |
| やき | yaki | 烧、烤（焼き） |
| やぶ | yabu | 草丛、灌木丛（藪）；「破绽」是 やぶれ（破れ） |
| ゆ | yu | 汤（热水，湯 ゆ） |
| ゆび | yubi | 手指 |
| ゆき | yuki | 雪 |
| ゆめ | yume | 梦 |
| よ | yo | 句末语气助词「よ」（表提醒）；与（给） |
| よい | yoi | 好 |
| よむ | yomu | 读 |

- 朗读重点：`やま`（山）是 ya + ma 两拍，读出「啊—吗」的滑动；`ゆき`（雪）同理。
- 发音没把握的词，用 MOJi辞书 / [jisho.org](https://jisho.org) 逐个听真人发音。
