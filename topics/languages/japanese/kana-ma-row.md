# ま行 · 五个音（ま み む め も）

> **逐行笔记第 7 篇**（对应 [每日计划](kana-plan.md) **10-19 周一**，与や行同日）。
> ま行是**中国人最容易读错的一行**：`ま/ば` 的鼻音差别、`び/み` 的混淆，都是中国人教材专门点名的难点。
> 总表与通用规则见 [五十音笔记](kana.md)。
> 📖 **页码说明**：假名与罗马字见教材 p.2 五十音图；「な行和ま行辅音与汉语 n/m 基本相同」见教材 p.4；ま/ば・み/び 的辨析是教材「Ⅳ 需要注意的发音」第 1 节（p.15–16）；笔顺对照表 A/B（p.8–9，PDF 25–26）；字源对照表 C/D（p.10，PDF 27）。鼻梁摸震法为通用练习技巧，非教材原文。

|------|--------|--------|--------|-----------------|-----------------|
| あ段 | ま | マ | ma | 3 / 2 | 末 / 万 |
| い段 | み | ミ | mi | 2 / 3 | 美 / 三 |
| う段 | む | ム | mu | 3 / 2 | 武 / 牟 |

- **笔画数为通行写法**：连笔书写时笔画会不同，写法以教材表 A（平）/表 B（片）的示范为准。
- ま行的易错点在 **`ま`/`ば` 的区分**（教材 p.15 点名）：两字口形相同、都是双唇闭合后发声，差别在气流走**鼻腔**（ま）还是**口腔**（ば）。

## 2. 发音要点（教材 p.4；ま/ば 辨析 p.15–16）

`m` 是**双唇鼻音**：上下唇**闭合**，气流从鼻腔出来（声带振动）。真正的难点不是 `m` 本身——汉语也有 m——而是它与浊音 `ば行` 的区分（见下）。

| 假名 | 要点 | 对比汉语的提醒 |
|------|------|----------------|
| ま ma | 双唇闭合、气流走鼻腔 | 与汉语「妈 mā」相近；难点在与浊音 `ば` 的区分 |
| み mi | 双唇闭合 + `i` | 后续注意与浊音 `び` 的区分 |
| む mu | 双唇闭合 + `u` 圆唇 | 别读成汉语「木 mù」的拖长 |
| め me | 双唇闭合 + `e` | — |
| も mo | 双唇闭合 + `o` | — |

**中国人两个高频难点**：

1. **`ま`（鼻音）与 `ば`（浊爆破音）**：两者口形相同、声带都振动。区别在**气流通道**——`ま` 经鼻腔共鸣，`ば` 双唇闭紧后放开、气流从口腔冲出。教材 p.15–16 的辨法：`ま`/`み` 发音时气流从鼻腔出（有鼻腔共鸣），`ば`/`び` 不从鼻腔出气，并点名部分中国人会把 び 发成 み；摸鼻法是配套的辅助技巧——把手放在鼻梁侧面，`ま` 能感到轻微震动，`ば` 没有。
2. **`み` 与 `び`**：同样是「鼻腔 vs 口腔」的差别（不是声带振动与否——两者声带都振动）。用上面的「摸鼻法」即可区分。

## 3. 笔顺（表 A p.8 / 表 B p.9，PDF 25–26）

- 平假名：ま 3 画、み 2 画、む 3 画、め 2 画、も 3 画。
- 片假名：マ 2 画、ミ 3 画、ム 2 画、メ 2 画、モ 3 画。
- `ま`（3 画）：一短横、一竖（从横上方下行）、底部一笔收环；片假名 `マ`（2 画）形如「7」——第 1 笔**横折连笔**成 7 形、第 2 笔补左侧短斜笔，和平假名写法完全不同。
- `み`（2 画）：上一笔左右两小弯相连，下一笔大弧收尾。
- `む`（3 画）：起笔两小笔（斜笔 + 短横）、末笔是**大环**。
- `め`（2 画）第一笔是**斜撇**，第二笔是带环的长弧；和 `ぬ`/`る` 的区别在于起笔方向。
- `も`（3 画）：两横 + 第三笔竖折带环；片假名 `モ`（3 画）是横、横、撇，无环。

## 4. 易混辨析

| 组 | 区分 |
|------|------|
| ま / な | `ま` 左上是「十」形交叉、底部收环；`な` 右上先一短撇、再一长横，下方两笔。 |
| み / ぬ / ね | `み` 2 画、上下两段；`ぬ` 2 画、大环封口；`ね` 2 画、带小竖和环。 |
| む / め | `む` 起笔是两小笔；`め` 起笔是斜撇。 |
| も / ほ | `も` 两横一竖折；`ほ` 左上多一小竖。 |
| マ / ア | 都两笔、形近：`マ` 第 1 笔**横折连笔**成「7」形、第 2 笔补左侧短斜笔；`ア` 是横 + 从横画右端向左下的**长撇**两笔（不要和 `マ` 的连笔写法混）。 |

## 5. 例词试读（本行假名为主，少量含已学行假名）

| 例词 | 罗马字 | 意思 |
|------|--------|------|
| ま | ma | 魔（悪魔 あくま 的 ま） |
| まい | mai | 舞（舞 まい）；枚（量词：一枚 いちまい） |
| もの | mono | 东西、物 |
| み | mi | 味（味道）；身 |
| みち | michi | 路、道路（道） |
| む | mu | 无（無料 むりょう 免费 的 む） |
| むし | mushi | 虫 |
| め | me | 目（眼睛） |
| めし | meshi | 饭（飯 めし） |
| も | mo | 藻；助词「也」（〜も） |
| もり | mori | 森林（森 もり） |
| もより | moyori | 附近、最近的（最寄り；最寄り駅＝最近的车站） |

- 朗读重点：`むし`（虫）的 `m` 是闭唇鼻音、双唇要碰；与浊音 ば行 的区分见第 2 节「摸鼻法」。
- 发音没把握的词，用 MOJi辞书 / [jisho.org](https://jisho.org) 逐个听真人发音。
