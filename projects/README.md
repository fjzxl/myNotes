# 🚧 Projects · 当前项目

> **正在做**的项目（与"归档"对应）。每个项目建一个子文件夹。

## 与 PARA 关系

这是 PARA 里的 **P (Projects)** —— 有明确目标和截止时间的事。

## 项目结构建议

```
projects/
├── project-name/
│   ├── README.md           # 项目目标、技术栈、进度
│   ├── tasks.md            # 任务清单
│   ├── notes/              # 会议记录、技术笔记
│   └── artifacts/          # 产出物（截图等二进制资源按仓库约定放 attachments/）
```

## 何时归档

- ✅ 项目交付 → 移到 `archive/projects/project-name/`
- ❌ 项目取消 → 移到 `archive/projects/cancelled/project-name/`
