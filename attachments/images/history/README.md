# 🖼️ History Images · 历史主题相关图片

> 服务对象：历史线笔记，总索引见 [MOC - history](../../../notes/MOC%20-%20history.md)。

## 子结构建议

```
history/
├── maps/                  # 地图
├── timelines/             # 时间轴

├── documents/             # 文献扫描
```

## 引用

在 `topics/history/*.md` 中用标准 Markdown 图片语法（绝对路径以 `/attachments/` 开头）：

```markdown
![秦朝疆域图](/attachments/images/history/maps/qin-dynasty.png)
```
