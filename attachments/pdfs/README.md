# 📄 PDFs · PDF 文件

> 重要 PDF 文档的存放位置（电子书、论文、报告等）。

## 组织方式

按主题分：

```
pdfs/
├── programming/
├── ai/
├── math/
├── history/
└── general/
```

## 引用

```markdown
详见 [[attachments/pdfs/programming/effective-cpp.pdf]]
```

或在 Markdown 里嵌入：

```markdown
<iframe src="../../../attachments/pdfs/..." ></iframe>
```

## 工具

- VS Code 装 `vscode-pdf` 扩展可直接打开
- Foam 也会把 PDF 当作节点显示在图谱里
