# 📥 Inbox · 闪念收集箱

> **用途**：随手抓到的灵感、临时想法、外链、文章截图等。**不在这里做整理**——定期（建议周末）把内容分流到 `topics/` 或 `notes/`。

## 使用规则

- 📝 **只管往里扔**，不用分类、不用排版
- 🗑 **不归档不删**：定期（每周/每月）清空一次
- 🔀 **定期整理**：把有价值的内容移走；没价值的就删

## 整理去向参考

| 类型 | 移去 |
|------|------|
| 编程知识、踩坑 | `topics/programming/...` |
| AI 相关 | `topics/ai/...` |
| 数学题、不等式证明 | `topics/math/...` |
| 历史事件、人物 | `topics/history/...` |
| 工具配置、技巧 | `topics/tools/...` |
| 跨主题概念 | `notes/*.md`（MOC 索引） |
| 当前项目 | `projects/...` |

## 工具配合

- VS Code Foam 扩展会自动识别此目录
- 每日笔记直接放 `journal/daily/`
- 长篇内容直接放 `topics/...`
