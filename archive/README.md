# 🗄️ Archive · 归档

> **用途**：不再活跃内容的归档地（完结的项目、废弃的草稿、旧结构遗留）。当前无归档内容。全库结构与整理节奏见仓库 [README](../README.md)。

## 使用规则

- 📦 **优先用 Foam 的移动/重命名（F2）移入**（自动重写双向链接）；手动移动则按原样整篇移入、不做内容加工，**移入后跑 `python check.py` 修正相对路径**；需要时按来源建子目录（如 `projects/`、`old-structure/`）
- 🏷 **保留原 frontmatter**，把归档日期写进 `updated` 字段
- 🔍 **仍可被 Foam 检索**：反向链接与图谱不断（前提是链接已按上面方式修正）

## 整理节奏参考

- 项目完结或搁置超过一个月：从 `projects/` 移入归档
- 归档内容若长期不再被引用，可考虑删除（Git 历史里仍可找回）
