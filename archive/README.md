# 🗄️ Archive · 归档

> **用途**：不再活跃内容的归档地（完结的项目、废弃的草稿、旧结构遗留）。当前无归档内容。

## 使用规则

- 📦 **按原样整篇移入**，不做内容加工；需要时按来源建子目录（如 `projects/`、`old-structure/`）
- 🏷 **保留原 frontmatter**，把归档日期写进 `updated` 字段
- 🔍 **仍可被 Foam 检索**：保留原有 wikilink，反向链接不断

## 整理节奏参考

- 项目完结或搁置超过一个月：从 `projects/` 移入归档
- 归档内容若长期不再被引用，可考虑删除（Git 历史里仍可找回）
